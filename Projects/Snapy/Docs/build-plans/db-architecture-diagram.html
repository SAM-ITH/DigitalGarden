Redis Data Structures

Cache Layer

Ephemeral data that auto-expires

Redis 7 — Cache, OTP, Leaderboards
otp:{phone}
String | TTL: 5 min
Stores the 6-digit OTP code for login verification
SET otp:+94771234567 "482901" EX 300
rate:otp:{phone}
Counter | TTL: 10 min
Rate limiting — max 3 OTP requests per phone per 10 min
INCR rate:otp:+94771234567 → reject if ≥ 3
leaderboard:grade:{gradeId}:week:{weekStart}
Sorted Set
Grade-level leaderboard — O(log n) rank operations
ZINCRBY leaderboard:grade:abc:week:2026-04-20 15.0 user-uuid
leaderboard:subject:{subjectId}:week:{weekStart}
Sorted Set
Subject-level leaderboard — per-subject competition
ZREVRANGE leaderboard:subject:xyz:week:2026-04-20 0 49 WITHSCORES
rate:{endpoint}:{identifier}
Counter | TTL: varies
General API rate limiting per user/IP
INCR rate:api:user-uuid → reject if over limit

Data Flow: Student Studies a Flashcard

End to End

What happens when a student answers a card

1
Student opens a unit and answers a flashcard
App records: { cardId: "uuid-1", rating: 3 (Good), reviewedAt: "2026-05-16T10:30:00Z" }. If offline, this is queued locally.
2
App sends batch of reviews to the server
POST /api/reviews/batch — Traefik routes this to the Review Service (port 8083). JWT token is verified by auth middleware.
3
Review Service processes each card in a database transaction
For each review in the batch, the service does 5 things in order:
card_reviews card_srs_state daily_activity user_streaks Redis leaderboards
3a
Insert review history
INSERT into card_reviews — permanent log of every review (who, what card, rating, when). Never updated or deleted.
3b
Run FSRS algorithm
Read current state from card_srs_state → feed into go-fsrs with the rating → get new stability, difficulty, due date → UPSERT back to card_srs_state.
3c
Update daily activity
UPSERT into daily_activity — increment cards_reviewed, correct_count, sessions_count for today. Powers the streak heatmap.
3d
Update streak
Update user_streaks — if last active yesterday, increment current_streak. If today, no change. If older, reset to 1.
3e
Update leaderboard scores
Calculate points: +1 base +2 accuracy bonus, multiplied by streak bonus (1x/1.5x/2x). ZINCRBY to Redis sorted sets for grade and subject leaderboards.
4
Return response to app
{ accepted: 10, rejected: 0 }. The app clears its local queue. Student sees session summary with score and XP earned.
